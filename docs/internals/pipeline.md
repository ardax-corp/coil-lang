# Compilation and execution pipeline

How a `.hy` program becomes running bytecode on the VM.

## Stages

1. **Parse** — the Pratt parser in `parser/` reads `.hy` source into an AST.
2. **Typecheck** — constraint-based inference in `compiler/src/typechecking/`. Generics are explicit (`fn f<T>`, `class Cell<T>`); `let` bindings are monomorphic (not Algorithm W). Diagnostics are source-anchored via ariadne. After infer, [`local_escape`](../../compiler/src/typechecking/local_escape.rs) records a fail-closed sidecar fact: ObjEnum / small-class values that never leave the frame (`NodeId` set on [`TypedSidecar`](../../compiler/src/typechecking/infer/sidecar.rs)). [`purity`](../../compiler/src/typechecking/purity.rs) records per-`DefId` [`EffectFlags`](../../compiler/src/typechecking/purity.rs) (host/FFI, escaping heap mutation, yield, `thread::spawn`, `gc::collect` / finalizers, I/O, attach/park; unknown is impure). LICM / fuse-select / index facts read those names from the sidecar — a proven-pure `CALL` is not a length or hoist barrier; an impure `CALL` is. [`index_facts`](../../compiler/src/typechecking/index_facts.rs) records `0 <= i < len(arr)` and length-stable for-in / helper-parameter pins on the same sidecar. Call/return ABI for heap `Option<T>` is the pointer niche; heap-heap `Result<T,E>` is `Ok` = pointer / `Err` = `pointer | 1`; `Option<int>` (any immediate inner), `Result<Ok,Err>` with an immediate `Ok`, and closed user payload enums with every variant's arity `<= 1` use a two-slot `[payload, tag]` ABI on a direct `CALL`/`RETURN` instead (`typechecking::return_layout`; excludes any name whose address is taken — see `typechecking::fn_value_escape`); everything else stays boxed `ObjEnum`. Codegen emits `IndexUnchecked` / `ArrayPin` / `IndexPinUnchecked` from those facts; `il::bounds` still rewrites counted loops. Yield clears facts (pins are not saved on `ObjCoroutine`). Ground generic helpers (bounded or unbounded) monomorphize to a direct `CALL` of a cloned body; escaped `let f = id` keeps `MakePolyFn` / `CallIndirect` / `BoxValue`.
3. **Codegen (stack IL)** — instruction lowering, not a semantic IR: `compiler/src/lib.rs` emits a compile-time stack IL (`compiler/src/il/`) with **symbolic labels** for jumps/joins (`IlOp::Jump` / `IlOp::Label`, not absolute PCs). Production emit is `CodeBuf` / `IlBuilder` only (`static_init` / `ffi_init` included); encode only in `il::lower`. `IlModule` is a cheap split of that one buffer at finalize, not a second language. Semantic structure is DefIds / typed sidecar. Escaping unary `Option<T>` of a ground heap object is a pointer niche (`0` / object address); heap-heap `Result<T,E>` is `Ok` = aligned pointer / `Err` = `pointer | 1`; a known ≤2-word layout (`Option<int>`, `Result<int, _>`, a closed arity-`<= 1` user enum) instead moves `[payload, tag]` on a direct `CALL`/`RETURN` (`CALL` bit 31 / `RETURN` operand `2`) — boxed at the call site unless the caller matches it directly or the value never leaves a two-slot `RETURN`; everything else stays boxed `ObjEnum` at function boundaries (archive major 4). In-frame locals the checker proved non-escaping unbox into payload/tag (or class field) slots; unique locals drop those slots after last use.
4. **Lower** — after multi-file link, `finalize_bytecode` **tree-shakes** unused function bodies (eager builtin dict thunks / unreferenced user fns) reachable only from `main` (and `test_cases` when `--include-tests`), then rebuilds an owning **`IlModule`** from the flat emit stream: per-body opts (`jump_thread`, `dead_block` after JMP/RETURN, `stack_dce`, `mem_fwd`/`copy_prop`/`dead_store`, **`canon`** (operand-order: `Const;Load` → `Load;Const` + commutative load/load slot order; int `ConstPool` demote when safe; Known-SP; `CanonStats`; no float reassoc), `algebraic`, optional **`cast_spill`** (default on — spill `CastIntToFloat` ahead of float chains; fuse stage0 accepts `LOAD;CONST`), `licm` (which first runs **`il::bounds`**: in a loop whose addressed arrays provably keep their length — element writes do, `ArrayPush`/impure calls/host/FFI do not — the invariant `LOAD a; ArrayLen; STORE t` triple and the `CONST; STORE t` pair behind `a[i] = 0` move to the preheader, whose store floors the cursor at `t + 1`; proven counted / stride `Index` / `StoreIndex` rewrite to Unchecked (`LE`/`GT` headers only; `LEQ`/`GEQ` are not proofs); unproven sites stay checked; pure user helpers on `b[i]` are not a length barrier), **`escape_analysis`**: fail-closed scalarization of non-escaping immediate-only `MakeArray` (arity ≤ 32) into consecutive frame slots (GC roots; calls/returns/fields/`ArrayPush`/computed elements keep the heap object; not named-local class SROA), **`loop_unroll`**: full unroll of counted natural loops with trip ≤ 8 (calls/break/nested refuse; `LEQ` for trip count only), **`ssa_gvn`**: virtual `Phi` VNs — redundant pure `Const`/`Load`+`Bin` → `Load` when the value already lives in a slot (`DIV`/`MOD` excluded; not SSA rename), **`invariant_store_elim`**: drop/sink invariant loop stores unread in the body, **`return_convoy`**: identical immediate `LOAD`/`CONST` into a return-label cluster → `*Return` (`JMP`, or `JMPF`/`JMPT` value-under-cond, or all-`JumpIfMatch`; not mixed across classes; cond/match/jump-only preds need Known join SP), **`bin_join_convoy`**: identical plain binop / `BinSlot*` tails → `BinReturn` or one shared `BinSlot*` before `RETURN` (same pred/SP gates)) + per-body **`cfg_gvn`** (intra-block + join-sink CSE, optional `ssa_gvn` inside `cfg_gvn_with`; Dup-CSE re-expanded to a second `LOAD` so fuse-select still sees both binop operands — COI-82 ceiling, no slot rename) + **`slot_promote_tell`** after GVN when enabled (`seek_back_edge` on Aggressive only; COI-97) + **`slot_promote`** (drops a `STORE t` reached with the cursor at `t + 1` — TOS already *is* slot `t` — plus the reload run in front of a `TailCall`; only when every remaining reference to the slot goes too, and after GVN so no slot is left with a def only a push provides), **`tos_carry`** (delay `STORE t` across slot-addressed `BinSlot*` so `LOAD t; STORE s` pops TOS; straight-line, Known-SP, no SSA), then **`multi_op_join_convoy`** on the concatenated buffer (SP join gates need whole-module height context; `JMP`/`JMPF`/`JMPT`/`JumpIfMatch` preds allowed) and finally **`invert_guard_branch`** (`JMPF A; JMP B; A:` → `JMPT B`; fusable guards invert too — fuse-select emits the `*Jmpt` twins, COI-87), then a **single** `il::lower`: fuse-select with **label / abs-jump barriers** (plus `*Return` join-on-window[0]), assign PCs once, encode `Vec<Byte>`. Hot-path ops are **typed `IlOp` variants** (`Load`, `Const`, `Bin`, `BinSlot*`, `*Return`, …) lifted on `CodeBuf::push` absorb; long-tail typed forms also include `HostInvoke` / `Print` / `GetField` / `SetField` / `ConstPool`; residual `IlOp::Byte` is rare (FORMAT/FFI/…). Enabled fuse patterns: const fold, `BinSlotImm` / `BinSlotSlot`, `CmpJmpf` / `LogNotJmpf` / `BinSlotImmJmpf` / `BinSlotSlotJmpf`, `BinSlotImmStore` / `BinSlotSlotStore` (the latter takes float ops as well as int — archive minor 2), packed multi-slot `LOAD`/`STORE` (`n≤3`), `LoadReturnSlot` / `ConstReturnImm` / `BinReturn`. CALL/TailCall/MakeCoro/CodePtr/MakePolyFn use `IlOp::Entry`; production abs JMP is rejected in lower — no post-lower peephole/`adjust_target` hot path. Tiny direct-call inlining judges candidacy on **IL emitting ops**, can expand a sole `ConstReturnImm`/`LoadReturnSlot`/`BinReturn` body or a pure ≤3-op micro-body, and remaps `BinSlotImm`/`BinSlotSlot` slots through caller temps. Per-function fuse-select was measured with no clear win on the `examples/perf/` baselines — production keeps a **single** fuse/PC lower after concat. Per-function `IlFunc` metadata (name, entry label, code span) is recorded on `CodeBuf` alongside `fn_bytecode_spans`.
5. **Archive** — `coil compile` wraps bytecode in a versioned `ArchivedProgram` envelope (packed `major.minor` in `common/src/archive.rs`) and writes `out.hyc` (or `-o`). Default `coil file.hy` compiles and runs **in memory** and does not read or write `out.hyc`. See [Debug line table](debug-info.md). **Policy:** `.hyc` does not record exec/exit/FFI-exec grants (no rkyv major for grants). Host grants (`--allow-attach`, `--allow-exec`, `--allow-exit`, `--allow-ffi-exec`, repeatable `--allow-dload STEM`) come from CLI flags / `Pipeline` `HostGrants` at **compile/typecheck**, not `coil.toml`. Gated calls without a grant **fail typecheck** (`E0406`–`E0411`); granted programs still emit the real `HostInvoke` / `FfiLoad`. **The artifact is the grant:** `coil run out.hyc` and packaged `coil-embed` do **not** re-apply allow flags; if the bytecode has the op, it runs. `dload` still checks native sha256 / `trusted` integrity and treats `search_paths` as locators. `dload("c")` stays denied even if flagged. Non-const `dload` paths are a compile error.
6. **Execute** — the VM in `machine/` runs `main` (or each `test("…")` case under `coil test`), from the in-memory compile or from a loaded `.hyc`.

```
AST + types → Stack IL (labels) → IL opts → lower/fuse-select → Vec<Byte> → .hyc → VM
```

Per-pass IL opt contracts (input / output / refusals / solo tests): [`compiler/src/il/opt/README.md`](../../compiler/src/il/opt/README.md).

## IL intent

The stack IL is **instruction lowering**, not a semantic IR:

1. **Emit** — codegen writes VM-shaped [`IlOp`](../../compiler/src/il/op.rs)s with **symbolic labels** (`Jump` / `Label` / `Entry`), not absolute PCs.
2. **Opt** — passes rewrite that same stream in place (contracts in [`il/opt/README.md`](../../compiler/src/il/opt/README.md)).
3. **Lower** — one `il::lower`: **fuse-select**, **assign PCs once**, encode `Vec<Byte>`. Production rejects residual absolute JMP; there is no post-lower peephole / `adjust_target` hot path.

Names, types, and call meaning live in **DefIds** and the **typed sidecar** (B1–B3). IL does not grow an HIR/SSA layer to hold that.

**Optional later** (not this cut): stop storing `Instruction` inside `IlOp::Bin`; drop `JumpIfMatch.arity` from the jump kind if tell/DCE can take stack effect from elsewhere (lower already encodes tag + target only); make `IlOp::Const` encoding-independent (value first, inline vs pool at lower); lift remaining `IlOp::Byte` or keep documenting the **cold set** (`FORMAT`, FFI, packed multi-slot `LOAD`/`STORE`, and anything `from_plain_byte` still leaves as `Byte`).


## Optimization levels

`Pipeline::set_opt_level` / CLI `-O` / `--opt-level` select an [`OptLevel`](../../compiler/src/il/opt/opt_level.rs) preset that fills `OptimizeOptions` (and tiny-inline budgets). Default is **Standard** — the same pass set as before this flag existed.

| Level | CLI | IL passes |
|-------|-----|-----------|
| None | `-O0`, `none` | algebraic / const-fold only |
| Basic | `-O1`, `basic` | None + jump threading, DCE, copy/mem forwarding |
| Standard | `-O2`, `standard` (default) | all currently-on production passes |
| Aggressive | `-O3`, `aggressive` | Standard + `seek_back_edge` (COI-97: measured fuse loss on mandelbrot; production `Standard` stays off) and a larger inline budget |
| Size | `-Os`, `size` | Standard without loop unroll or shared-return cloning |
| Debug | `-Og`, `debug` | Basic only (no slot promotion, escape SROA, unroll, or GVN) |

`None ⊂ Basic ⊂ Standard ⊂ Aggressive` on enable flags. Size and Debug are independent axes.

Branch layout (COI-128) is **on** by default (`branch_optimization`). It inverts a terminating then-arm after `JMPF`/`JMPT` only when operand height is Known at the jump and along the moved arm, and mints a module-wide-unique label for the cold region so later functions cannot bind the same id. A profile that says the fall-through is hot leaves the layout alone.

Basic-block reordering (COI-129) is **on** by default (`block_reordering`). It only sinks jump-only terminating blocks that are not fall-through successors and are not unconditional-jump joins, so labels and branch polarity stay put.

Iterative optimization (COI-130) is **off** by default (`iterative_optimization`). When enabled, the full IL pass pipeline re-runs until a round is a no-op or `max_optimization_iterations` (default 10, clamped to 1..=10). That lets late rewrites such as `invert_guard_branch` expose DCE for a later round without changing one-shot production behavior.

Optimization statistics (COI-131) are **off** by default (`collect_stats` / CLI `--opt-stats` and `--opt-stats-json`). When enabled, each named IL pass records ops added/removed, load/store eliminations, unrolls, branch layouts, and block moves; tiny-inline sites increment `functions_inlined`. Human text or a single JSON object is printed to stderr after a source compile. Collection clones the op buffer only while the flag is on.

Profile-guided optimization (COI-132) is optional compile-time plumbing, not a proven win on the benchmark matrix. Two-phase. Both compiles share a **cleanup** mid-IR prefix (jump thread, DCE, mem/copy peeps, canon, algebraic, cast spill). `--pgo-instrument` then assigns stable sites (`fn_index * SITE_STRIDE + local`) and inserts stack-neutral `pgo_hit` HostInvoke counters—**without** running profile-sensitive decision opts (LICM, unroll, escape, layout). `--pgo-use-profile=<file>` loads versioned JSON (`function_counts`, `block_counts`, `branch_counts`, optional `fn_checksums`), maps counts onto the cleanup CFG (mismatch → ignore that function), then runs decision opts; branch layout and block reorder stay **last** among IL consumers. Heat lookups use the same site keys (and BFI-lite frequencies). A newer `version` is refused and compilation continues with heuristics; a missing file is ignored. Tiny-inline skips functions whose recorded count is zero. `--pgo-generate-profile=<file>` writes VM counters from an instrumented run (including checksums from that compile), or the current/empty template if none were collected.

The IL is **compile-time only**; the VM implements the representation-boundary and numeric-chain opcodes and archive minor 5 records them.

## Archives (`out.hyc`)

Default `coil file.hy` compiles and runs in memory. It does **not** read or write `out.hyc` (integration tests assert this). An existing `out.hyc` beside the entry is left untouched; if it looks stale the CLI may warn, but the in-memory compile still runs.

`coil compile [file.hy]` writes `out.hyc` (or `-o`). `coil run out.hyc` loads that archive and **warns** when recorded sources are newer; it does **not** rebuild. Missing / corrupt / incompatible archives fail instead of compiling from source.

Incrementality (fingerprint-based reuse of a compile) is a later design, not current CLI behavior.

## Multi-file programs

With a `coil.toml`, the pipeline discovers dependencies via `use` / `mod`, compiles each file with a namespace prefix into one shared IL buffer, and **lowers once** after linking. The **entry file** uses the empty namespace. See [Modules](https://github.com/ardax-corp/coil-website/blob/main/src/content/docs/references/modules.md) and [Project config](https://github.com/ardax-corp/coil-website/blob/main/src/content/docs/references/project-config.md).

## Opcode discipline

New `Instruction` variants are **append-only** (preserve `#[repr(u8)]` discriminants). Additive changes bump the archive **minor**; incompatible changes bump the **major** (reset minor). Loaders accept the same major when the archive minor is ≤ the runtime minor. The release VM `promise!` ceiling must track the last variant. Selected builtin-related opcodes are listed in [opcodes.md](opcodes.md).
